
# getstart.txt
# AI News Intelligence API (Cloudflare Workers + D1 + KV)
# Production-ready architecture for Copilot

## PROJECT OVERVIEW
Event-based AI/Tech news pipeline:
RSS → Normalize → Dedup → Rule Engine → Store (D1) → Cache (KV) → API → RSS output

LLM is NOT part of core pipeline.

---

## ARCHITECTURE

RSS FEEDS
  ↓
FETCH WORKER (Cron)
  ↓
NORMALIZER
  ↓
DEDUPLICATION
  ↓
RULE ENGINE (SCORING)
  ↓
D1 STORAGE
  ↓
KV CACHE
  ↓
API + RSS FEED

---

## EVENT MODEL

type Event {
  id: string
  title: string
  description: string
  url: string
  source: string
  published_at: number
  fetched_at: number
  category: "ai" | "dev" | "crypto" | "tech"
  score: number
  cross_sources: number
}

---

## D1 SCHEMA

CREATE TABLE events (
  id TEXT PRIMARY KEY,
  title TEXT,
  description TEXT,
  url TEXT,
  source TEXT,
  category TEXT,
  published_at INTEGER,
  fetched_at INTEGER,
  score REAL,
  cross_sources INTEGER,
  created_at INTEGER
);

CREATE TABLE sources (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT,
  url TEXT,
  type TEXT,
  reliability REAL,
  active INTEGER
);

## PIPELINE

1. FETCH RSS
2. PARSE XML
3. NORMALIZE
4. DEDUPLICATE
5. SCORE (RULE ENGINE)
6. STORE IN D1
7. CACHE HOT ITEMS IN KV
8. EXPOSE API + RSS

---

## RULE ENGINE

FINAL SCORE = 0 - 100

SOURCE SCORE:
OpenAI/Google/NVIDIA → 10
GitHub → 9
HN → 9
arXiv → 8
Reddit → 6
Dev.to → 5

FRESHNESS:
<1h = 10
<6h = 7
<24h = 4

ENGAGEMENT:
GitHub stars/1000 max 10
HN points/100 max 10

CROSS SOURCE:
2 sources = +4
3-4 = +8
5+ = +12

TOPIC:
AI = +8
DevTools = +6
Crypto = +4

BOOST:
GitHub 5k+ stars/day = 100
HN 1000+ = 100
Official AI release = 95

PENALTY:
Spam = -15
Clickbait = -10
Duplicate = -8
